1 つの条件を変えたときの φtotal

条件・流量の内訳と，4 つの条件（Uco，φco，U0，φ0）それぞれを変えたときの φtotal を，表とグラフ付きの .xlsx で保存する．

計算式と前提

φtotal = [ (F0 + Fco) / (A0 + Aco) ] / (F/A)st
Qi = Ui Si，　S0 = πD0² / 4，　Sco = π [ Dco² − (D0 + 2t)² ] / 4
Fi = Qi φi / (φi + s)，　Ai = Qi s / (φi + s)
s = (A/F)st = νO₂ / 0.21
  • F，A は燃料・空気の体積流量，s は体積基準の理論空燃比，νO₂ は燃料 1 mol の完全燃焼に必要な O₂ のモル数．
  • 流速は出口断面の平均流速．主流と環状流は同じ温度・圧力とし，体積比＝モル比で扱う．
  • 空気中の O₂ は 21 vol%．周囲空気の巻き込みは含めない．
  • 流量 [L/min] は流速を定義した温度・圧力での値．マスフローコントローラの基準状態が異なる場合は換算が必要．
