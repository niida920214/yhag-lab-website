# Google 3D Tiles フライトシミュレーター（最小プロトタイプ）

CesiumJS で Google のフォトリアル3Dタイルを表示し，自作の6自由度飛行力学モデルでジェット機を飛ばします．ビルド不要で，静的ファイルをローカルサーバーで配信するだけで動きます．

## 準備

1. Google Cloud Console でプロジェクトを作り，課金を有効にします．
2. 「APIとサービス」から **Map Tiles API** を有効にします．
3. 「認証情報」でAPIキーを作成します．公開しない前提でも，キーの制限（HTTPリファラーを `http://localhost:*` に限定，APIを Map Tiles API に限定）をかけておくと安心です．
4. `config.js` を開き，`GOOGLE_MAPS_API_KEY` にキーを貼り付けます．`config.js` は `.gitignore` に入れてあるので，Gitで公開する場合もキーは含まれません．

料金・無料枠・利用規約（帰属表示の必須，データのキャッシュ禁止など）は変わることがあるので，Google Maps Platform の公式ページで確認してください．

## 起動

ES Modules を使うので，`index.html` をダブルクリックで開くのではなく，ローカルサーバー経由で開く必要があります．このフォルダで次のどちらかを実行します．

```
python -m http.server 8000
```

```
npx serve .
```

ブラウザで `http://localhost:8000`（serve の場合は表示されたURL）を開きます．Chrome か Edge を推奨します．

| C | 操縦桿とラダーを中立に戻す |
| M | キーボード操縦／マウス操縦の切り替え |
| J | コックピットパネルの表示切替 |
| K | オートパイロット |
| L | 着陸灯 |
| マウスホイール | スロットル（マウス操縦時） |
| W S | スロットル |
| [ ] | ピッチトリム |
| F / E | フラップを下げる／上げる（UP・1・2・3・FULL の5段階） |

Xbox配列のゲームパッドにも対応しています（左スティックで操縦，右スティック左右でラダー，RT/LTでスロットル，Aでブレーキ）．

## コックピットの計器パネル

画面下にパネルが出ます（Jキーで表示切替）．左から順に次の3つです．

- **PFD（主飛行表示）**：人工水平儀，バンク角指標，左右に速度計（ノット）と高度計（フィート），右端に昇降計．迎角と荷重倍数も表示します．失速角に近づくと迎角の数字が赤くなります．
- **ND（航法表示）**：方位盤，対地速度，電波高度（地面までの高さ）．オートパイロットの目標方位はピンクの線で出ます．
- **エンジン計器**：N1（推力の出方）の縦バー，白い横線がスロットルの指令値です．その下にフラップ・脚・ブレーキなどの状態が並びます．

パネル下のスイッチ類はすべてクリックできます．

| スイッチ | 動作 |
|---|---|
| GEAR | 脚の上げ下げ．緑が DOWN，橙が UP |
| FLAPS ▲▼ | フラップを1段ずつ．実機と同じようにゆっくり動きます |
| PARK | パーキングブレーキ．入れっぱなしだと離陸できません |
| TRIM ▲▼ | ピッチトリム |
| A/P | オートパイロット．右の欄に高度（ft）・方位（度）・速度（kt）を入れてEnterで目標を設定します．空欄にするとその項目は制御しません |
| LAND / BCN / STRB | 灯火（現状は表示のみ） |
| 切替 / 中立 | 視点切替，操縦桿を中立に戻す |

オートパイロットは，高度・方位・速度を目標値に向けて保つ簡易的なものです．実機の自動操縦とは別物で，高度は±30 m，方位は数度の誤差が残ります．切ったときは舵がその位置のまま残るので，「中立」を押すかCキーで戻してください．

数値の入力欄にカーソルが残っているとキー操作が効かなくなります．Enterを押すか，画面のどこかをクリックしてください．

**マウス操縦**：Mキーか `config.js` の `INPUT_MODE: 'mouse'` で切り替えます．カーソルの位置がそのまま操縦桿の位置になり，画面中央が中立です．カーソルを下に動かすと機首上げ，左右でロールします．中央付近は細かく，端に行くほど大きく舵が切れます．点線の四角が舵いっぱいの範囲で，広さは `MOUSE_RANGE` で調整できます．ラダー（A/D），フラップ，脚などはキーボードのままです．切り替えた瞬間にカーソル位置の舵角になるので，カーソルを画面中央に置いてから切り替えると安全です．

**墜落**：地面や建物にぶつかると爆発し，火球・炎・破片・黒煙が出ます．爆発音はブラウザ内で合成しています．音を消したいときは `SOUND: false` にします．

**操縦桿のモード**：標準の `STICK_MODE: 'hold'` では，矢印キーを押した分だけ舵が動き，離してもその舵角が保持されます（自動で中立に戻りません）．画面下中央の四角が操縦桿の位置です．Cキーで中立に戻せます．従来の「離すと中立に戻る」動きにしたい場合は `'spring'` にします．

なお，飛行機そのものが持つ安定性（機首が釣り合いの迎角に戻ろうとする性質など）は実機と同じく残してあります．これは自動操縦ではなく空力の性質で，これを消すと実機にない挙動になり操縦不能になります．

**離陸の手順（大型機）**：`START: 'runway'` にして，フラップを下げた状態でスロットル全開（W長押し），約140ノットで↓を少し押して舵を引き，機首が8°前後まで上がったらCで中立付近に戻します．テールストライクに注意してください．上昇したら G で脚を上げ，F でフラップを上げ，`]` でトリムを取ります．

## 機体

`config.js` の `AIRCRAFT` で選びます．
- `'airliner'`：超大型4発機．重量・寸法・推力をA380級の公表値に合わせた飛行モデルです．外観は `src/model.js` がプログラムで生成するオリジナルデザインです．
- `'jet'`：小型の双発ジェット．軽快に動きます．

自分で入手した3Dモデル（.glb/.gltf）に差し替えることもできます．`models` フォルダに置き，`config.js` の `MODEL` にパスを書きます．配布サイトのモデルを使う場合は，ライセンス（個人利用の可否，クレジット表記など）を必ず確認してください．向きや位置がずれるときは `yawDeg`（例：90や180），`scale`，`offset` で合わせます．

```
index.html        画面とHUDのスタイル

src/aircraft.js   機体パラメータ（質量，慣性，空力係数など）
src/model.js      オリジナル外観の3Dモデル生成（GLB）
src/explosion.js  墜落時の爆発演出（パーティクル，火球，爆発音）
src/cockpit.js    コックピットの計器パネルとスイッチ
src/autopilot.js  簡易オートパイロット
src/controls.js   キーボード／ゲームパッド入力
src/hud.js        HUDの描画
```

## しくみ

- **座標**：機体の位置は緯度・経度・楕円体高で持ち，速度と角速度は機体軸（x前，y右，z下）で積分しています．描画時に NED → ECEF へ変換して Cesium に渡しています．
- **物理**：240 Hz の固定時間刻みで，並進は m(v̇ + ω×v) = F，回転は Iω̇ = M − ω×(Iω)，姿勢はクォータニオンで積分しています．計算は1ステップ数マイクロ秒程度なので，負荷のほとんどは3Dタイルの描画です．
- **空力**：揚力は迎角に比例し，失速角（14°）を超えると平板の特性へなめらかに移るモデルです．抗力は放物線ポーラ，モーメントは安定微係数・操舵微係数の線形和です．
- **地面**：数フレームごとに `scene.sampleHeight` で機体直下の3Dタイル表面の高さを取得し，3点の脚をばね・ダンパーとして接地力を計算しています．建物の屋上も「地面」として扱うので，ビルにぶつかると墜落判定になります．
- **高度表示**：HUDの高度は楕円体高です．東京付近では平均海面より約37 m高い値になります．

## 注意点

- `runway` の開始座標は概算です．Google Maps で羽田C滑走路（34R）の南端を右クリックして表示される座標を，`config.js` の `START_OVERRIDE` に `{ lat: ..., lon: ... }` の形で入れると正確になります．
- 機体の係数は教科書的な値から作った「それらしい」もので，特定の機種の再現ではありません．
- 重い場合は `config.js` の `TILE_QUALITY` を 24〜32 に上げると軽くなります．

## 発展のアイデア

- JSBSim の機体定義（F-16 など）から係数を移植して実機に近づける
- 空力係数をマッハ数・迎角のテーブル補間にする
- 風・乱気流モデル，ILSの表示，着陸スコア
- 舵面（エルロン・エレベーター）やフラップを3Dモデル上で動かす
- オートパイロットに垂直速度モードやILS追従を足す
- 灯火を実際に光らせる（着陸灯のスポットライト，ストロボの点滅）
